Script-aware validation can fail when an application's Unicode data predates the text it receives. Perl 5.44 adds stable Unicode 17 support, including the new Sidetic script in the U+10940–U+1095F range. You can test its script property directly instead of maintaining a handwritten character list. This example checks a constructed character and contrasts finding Sidetic text with requiring an entirely Sidetic string, without depending on installed fonts.

```perl
use v5.44;
use strict;
use warnings;

my @samples = (
    ['Sidetic U+10940', chr(0x10940)],
    ['Latin A',        'A'],
    ['Digit 7',        '7'],
);

for my $sample (@samples) {
    my ($label, $character) = @$sample;
    my $is_sidetic = $character =~ /\p{Script=Sidetic}/ ? 1 : 0;
    say "$label: $is_sidetic";
}

my $candidate = chr(0x10940) . 'A';
my $contains_sidetic = $candidate =~ /\p{Script=Sidetic}/ ? 1 : 0;
my $only_sidetic = $candidate =~ /\A\p{Script=Sidetic}+\z/ ? 1 : 0;

say "Mixed text contains Sidetic: $contains_sidetic";
say "Mixed text is entirely Sidetic: $only_sidetic";

```

Expected output:

```text
Sidetic U+10940: 1
Latin A: 0
Digit 7: 0
Mixed text contains Sidetic: 1
Mixed text is entirely Sidetic: 0

```

The program constructs a Sidetic character with `chr(0x10940)`, so the source needs no literal non-ASCII characters. The sample list also includes a Latin letter and an ASCII digit as negative controls. For each sample, `=~` applies a regular expression containing `\p{Script=Sidetic}`. The conditional operator `? :` converts the match result into an explicit `1` or `0`, making the output independent of glyph rendering.

The final two checks illustrate an important validation distinction. An unanchored property match answers whether the string contains a Sidetic character anywhere. It therefore succeeds for the candidate containing both the constructed character and a Latin letter. The pattern `\A\p{Script=Sidetic}+\z` instead requires one or more Sidetic characters across the entire string, so that same candidate fails. Here, `\A` and `\z` mark the absolute start and end of the string; `+` also means an empty string would fail.

Use the property when your rule concerns script membership rather than merely a numeric position within a block. Do not assume every code point in the Sidetic range satisfies a particular property without checking it. Script membership alone also does not establish that text is linguistically valid or suitable as an identifier.

All printed labels and results are ASCII, so this demonstration needs no output encoding layer. Applications that print the actual characters should explicitly encode standard output as UTF-8.

Example tested with Perl 5.44.
