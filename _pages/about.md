**Useful Perl features, one small tip at a time.**

Talking to Perl programmers, I've noticed how easy it is to miss new additions
to the language. We learn Perl, get comfortable with it, and get on with writing
code. Meanwhile, Perl keeps moving.

Modern Perl Tips is a chance to catch up a little at a time. Each tip takes a
useful feature you might not have come across, shows how it helps with an
everyday problem, and points you towards the documentation. You might discover
a clearer way to write something you've been doing for years.

## Get into the perldelta habit

Whenever a new version of Perl is released, take a few minutes to
[read perldelta](https://metacpan.org/dist/perl/view/pod/perldelta.pod). It's the
release notes: new features, changes in behaviour, deprecations, and bug fixes.
You don't have to use every new feature. Knowing what's available is a good
start.

You can also run `perldoc perldelta` to read the release notes that came with
your installed Perl.

## Keep your Perl moving

You don't have to upgrade on release day, but do keep your version of Perl
reasonably up to date. Read the release notes, test your applications, and make
upgrades a regular habit. It's much easier to use a helpful new feature when
the Perl you're running supports it.
